# LLM Agent для сетевого взаимодействия

Курсовой проект по дисциплине «Сетевые технологии АСОИУ». Сервис принимает документацию и вопрос, получает полный ответ от локальной LLM Ollama, делит его на три последовательных сегмента и передаёт сегменты во внешний транспортный сервис.

## Архитектура и поток обработки

```text
Клиент
  │
  └── POST /ask { documentation, question }
          │
          ├── генерация уникального message_id
          ├── запрос к Ollama через /api/generate
          │      модель: qwen2.5:7b, stream: false
          ├── разбиение полного ответа на 3 сегмента по символам
          ├── последовательная отправка сегментов
          │      POST http://10.241.116.6:8080/segment
          └── ответ клиенту со статусом и количеством отправленных сегментов
```

## Возможности

- REST API на FastAPI;
- получение ответа от локально запущенной Ollama;
- формирование промпта на основе документации и вопроса;
- накопление полного ответа до начала передачи;
- равномерное разбиение ответа на три сегмента;
- передача каждого сегмента с идентификатором сообщения и порядковым номером;
- проверка состояния сервиса через `GET /health`;
- асинхронная обработка HTTP-запросов с `httpx`;
- подробное логирование обработки запроса, сегментации и ошибок;
- поддержка CORS для клиентских приложений.

## API

### `POST /ask`

Принимает документацию и вопрос, обращается к Ollama, делит ответ на три сегмента и передаёт их транспортному сервису.

Запрос:

```json
{
  "documentation": "Функция calculate() выполняет вычисления по формуле",
  "question": "Как работает функция calculate?"
}
```

Ответ:

```json
{
  "status": "ok",
  "segments_sent": 3,
  "message_id": "1746355227_a1b2c3d4"
}
```

### `GET /health`

Проверяет доступность FastAPI-сервиса.

```json
{
  "status": "ok"
}
```

## Формат сегмента

Каждый сегмент передаётся во внешний транспортный сервис в формате:

```json
{
  "message_id": "1746355227_a1b2c3d4",
  "total_segments": 3,
  "segment_number": 1,
  "payload": "часть полного ответа"
}
```

- `message_id` — идентификатор исходного запроса;
- `total_segments` — общее число сегментов;
- `segment_number` — номер текущего сегмента, начиная с 1;
- `payload` — содержимое сегмента.

Сегменты формируются функцией `split_into_segments`: текст распределяется между тремя частями максимально равномерно по количеству символов.

## Стек технологий

- **Python 3.11+**;
- **FastAPI 0.104.1** — REST API и валидация запросов;
- **Uvicorn 0.24.0** — ASGI-сервер;
- **httpx 0.25.2** — асинхронные HTTP-запросы к Ollama и транспортному сервису;
- **Pydantic 2.5.0** — модели входных данных и сегментов;
- **Ollama** — локальный inference-сервис;
- **Qwen 2.5 7B** — используемая локальная языковая модель;
- **Go transport service** — внешний endpoint приёма сегментов;
- **logging** — журналирование выполнения и ошибок.

## Требования

- Python 3.11 или новее;
- установленная Ollama с доступной моделью `qwen2.5:7b`;
- работающий транспортный сервис по адресу `http://10.241.116.6:8080/segment`;
- доступные сетевые подключения к Ollama и транспортному сервису.

## Установка и запуск

Создайте окружение и установите зависимости:

```bash
python -m venv .venv
source .venv/bin/activate        # macOS / Linux
# .venv\Scripts\activate       # Windows PowerShell
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Запустите Ollama и убедитесь, что модель установлена:

```bash
ollama serve
ollama pull qwen2.5:7b
```

Запустите FastAPI-сервис:

```bash
python main.py
```

Сервис будет доступен по адресу `http://localhost:8000`, интерактивная документация FastAPI — по адресу `http://localhost:8000/docs`.

Проверьте доступность сервиса: `curl http://localhost:8000/health`. В ответ должно прийти `{"status":"ok"}`.

## Примеры использования

### cURL

```bash
curl -X POST http://localhost:8000/ask \
  -H "Content-Type: application/json" \
  -d '{
    "documentation": "Функция sum(a, b) складывает два числа",
    "question": "Как работает функция sum()?"
  }'
```

### Python

```python
import httpx

response = httpx.post(
    "http://localhost:8000/ask",
    json={
        "documentation": "User имеет поля: id, name, email",
        "question": "Какая структура у User?"
    }
)

print(response.json())
```

## Обработка ошибок

| Ситуация | Поведение |
|---|---|
| Ollama недоступна | FastAPI возвращает HTTP 500 с описанием ошибки подключения |
| Ollama возвращает пустой ответ | Возвращается HTTP 500 |
| Таймаут запроса к Ollama | Возвращается HTTP 500 после таймаута 300 секунд |
| Ошибка отдельного сегмента | Ошибка записывается в журнал, обработка остальных сегментов продолжается |
| Транспортный сервис недоступен | Ошибка подключения записывается в журнал, число успешно отправленных сегментов возвращается клиенту |
